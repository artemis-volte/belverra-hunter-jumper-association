Association rules

Rulebook

This rulebook is written for a fictional Topline association and can be edited directly in rulebook.html.

Disciplines

BHJA recognizes two disciplines only: Hunters and Jumpers. Equitation is not offered.

Leaderboard Points

1st10
2nd7
3rd5
4th3
5th1

Hunter Advancement

Hunter advancement is based on top-three placings. A horse must earn 20 top-three placings at the prior level before moving up.

Jumper Advancement

Jumper advancement is based on qualification points earned at the previous jumper level. Qualification points are tracked separately from leaderboard points.

Starting Levels

Hunter horses may start no higher than Children’s / Adult Hunter. Jumper horses may start no higher than 3'6" / 1.10m.

Special Classes

Optional parallel classes include Green Hunters, In-Hand / Breeding, and 5-, 6-, and 7-Year-Old Young Jumper classes.

CSV Rules

The site is set up to read the Topline show-results CSV export directly. Replace results.csv with the exported file, keeping this exact column order:

Species,Show,Date,Class,Discipline,Level Key,Level,Place,Score,Animal,Breed,Stable,Owner

The leaderboard script automatically converts each row into BHJA standings data:

  • Animal is treated as the horse name.
  • Place is used to calculate leaderboard points: 1st = 10, 2nd = 7, 3rd = 5, 4th = 3, 5th = 1.
  • Hunter rows automatically earn 1 top-three credit when the placing is 1st, 2nd, or 3rd.
  • Jumper rows automatically use the placing points as qualification points for move-up tracking.
  • Rows for non-horse species are ignored if the Species column is present.

You no longer need to manually add columns for leaderboard_points, qualification_points, or top_three. The website calculates those from the Topline export.
